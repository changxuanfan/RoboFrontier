Same tasks. Different organizations.

Single uses one Controller. Controller + Worker assigns a permanent Worker to each arm. Worker–Worker coordinates through peers. Adaptive lets its Controller create and retire delegates as needed.

New tasks start directly after the required initial sessions are bound. Reading and planning count toward the START-based task clock. Completion and process events are evaluated separately. These static initial views demonstrate neither task success nor complete physical qualification.

Native Codex supports these four configurations. Native Claude exposes engineering entries for all four topologies, including persistent Controller + Worker and Worker–Worker sessions. Formal scored Claude qualification remains closed pending real-provider lifecycle acceptance.

Task rules and completion
  1. Deliver the three requested source-identity items to each destination board. Station IDs identify inventory and destination orders, not exclusive robot ownership.
  2. Transfers may be direct airborne handovers or safe stable tabletop staging. There are no marked or mandatory intermediate regions, predefined buffer positions, prescribed routes or fixed transfer pairs. The planner chooses whether to wait, stage or hand over. Establish receiving support before releasing an airborne item.
  3. Each final position shows the required color and shape: a square for a cube and a circle for a cylinder, 1.4 times the object width or diameter. These are visual identity cues, not enlarged acceptance tolerances. Slot numbers and source identities disambiguate orders.
  4. L1: release stably at the final board targets. L2 and L3: both flat blades must enter the real blind slots and the item must be released, seated and stable. L2 has a fixed board; L3 has the same three inline sockets on a passive spring-supported z/roll/pitch board. Preserve prior placements and allow gripper opening and withdrawal clearance.
  5. Cubes have 60 mm sides; cylinders have 60 mm diameter and height. Blades initially point up or sideways. Grasp, airborne reorientation, receiving grasp and subsequent insertion must form a feasible continuous sequence. Allocation, routes and independent concurrent work are planner choices; minimize unnecessary cycling, staging and regrasping while maintaining real support and collision clearance.
  6. Only robot actuators and real contacts may affect the live task. No hand welds, object state writes, resets, hidden state tools or runtime physics edits.
