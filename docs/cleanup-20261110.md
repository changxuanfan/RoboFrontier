# Cleanup log, 2026-11-10

This page records what the 2026-11-10 cleanup removed from the repository, why,
and how to get it back. Nothing listed here is lost: every file is in Git at the
tag `archive/pre-cleanup-20261110` (commit `616cb709`, the `main` the cleanup
started from).

Restore one path:

```sh
git checkout archive/pre-cleanup-20261110 -- PATH
```

Earlier removals (the 2026-11-03 prune) are indexed in
[`benchmark/pruned-paths.json`](../benchmark/pruned-paths.json) with their own tag.

The cleanup runs as a series of pull requests. Each one adds a section below.

## Before the pull requests: local data

Not in Git, so listed only in summary. Old worktrees, per-run source copies and
duplicate checkouts were removed, leaving one checkout on `main`. Local test and
smoke runs were deleted. Formal runs were deleted only where a backup already
held them. Unmerged branches were kept as local `archive/branch/*` tags.

## PR 1: dead code, one-off scripts and retired pages

Removed because nothing current calls them, they were one-off tools for earlier
scene or video revisions, or a newer entry replaces them. The release is being
frozen, so scene builders and video editors for earlier revisions are no longer
needed in the tree.

Tests that covered only removed code were removed with it (31 files). Tests
that also covered kept code keep those cases. The Codex launch-profile cases
moved to `tests/test_codex_launch_profiles.py`, and the task data check moved to
`tests/test_site_data.py`.

Kept for a later pull request, because current code or documents still use them:
`scripts/benchmark.py` (the Codex entry, until the engines are unified),
`scripts/mosaic.py` (with `robofrontier/suite/mosaic_delivery.py`), the
builders and checkers the release work will replace, and the demo's `Simulation`
class in `robofrontier/sim.py` with `build_scene` in `robofrontier/scene.py`: the
historical Dial and Mosaic package checks pin the exact bytes of `sim.py`, so it
changes together with those checks.

Behavior changes:

- `robofrontier factory submit --queue` runs `robofrontier factory run` on each
  node. Render plans made by the removed `scripts.factory_server`, which have no
  frozen configuration, are refused; prepare them again.
- The README benchmark figure (`scripts.site_media explainer`) now takes a
  folder of initial-state renders instead of the atlas images.
