RoboTeam

Benchmarking Vision-Based Multi-Agent Control of Many Robot Arms in Real Time

Agents call one robot tool and write their own code to control 4 to 16 robot arms. The world never pauses while they think, and they see it only through cameras. Watch them pass timbers, plug parts into sockets, build pictures from hundreds of cubes and crack a code on spring-loaded dials.

Tasks

Four jobs that no arm can finish alone.

Each task type comes at three team sizes and three difficulty levels. A larger team adds arms and work to divide. A higher level makes the same job physically or visually harder.

Each image is the task at its start. Hover to preview a run, select to open it.

How it works

A world that never waits, seen only through cameras.

Every model drives the same simulated Franka arms through the same tool, sees the same cameras and follows the same rules.

01

Real time

The world advances with the clock and never waits for an agent. A real robot would not wait for a model, and pausing for one agent would also stop its teammates.

02

Camera images only

Agents ask for RGB images from 14 to 69 fixed cameras and read the state of the arms. They never receive object positions, depth or contacts.

03

One robot tool

Arms move only through one tool: move an arm to a pose, or open, close or grasp with a gripper. Every failed motion or grasp is visible.

04

Their own code

Agents also have a shell, file editing and Python, for example to measure object positions in an image. A sandbox keeps them away from the simulator and the evaluator.

Four ways to organize the agents.

The adaptive system is the most flexible: one controller holds every arm, forks itself into delegates when work can be shared, and takes the arms back when their jobs end. The other three keep a fixed structure.

Results

Not yet fast, cheap and reliable at once.

Fourteen conditions each run the 36 tasks once: four agent systems, two changes to what the agent sees or may use, two harnesses and six models.
